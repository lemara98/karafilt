**Detailed description**

```
把任何一個分頁變成卡拉OK。Karafilt 會即時消除你正在看的分頁裡的人聲 - YouTube、
各種串流網站，只要有音樂在播都行 - 並在側邊面板顯示跟著音樂跑的同步歌詞，讓你
直接跟著唱。完全免費。

怎麼用
用免費的 Karafilt 帳號登入，然後在正在播音樂的分頁點一下 Karafilt 圖示 - 側邊
面板就會打開，帶著那首歌的歌詞。按下 Start Filtering（或 Ctrl+Shift+K），人聲
就消失了。

功能
• 即時去人聲 - 完全在你的瀏覽器裡運算（WebAssembly），不上傳、不用等
• 三種免費模式：Spectral（均衡）、Spectral Deep（連和聲一起壓掉）、Basic
  （最輕量）
• 同步歌詞與卡拉OK highlight - 有逐字時間軸的歌會一個字一個字亮起來；專注模式
  把正在唱的句子放大
• 中文歌詞正常顯示，不再是一堆方框；逐字時間軸也是真的逐「字」跑
• 認得中文圈的影片命名方式：【官方MV】、「完整版」、動態歌詞、高清 等標籤
• 同一首歌有很多版本時，由你自己挑對的那一個
• 人聲／伴奏比例滑桿 - 想要的話可以留一點原唱當引導
• 任何會播音訊的網站都能用
• 幫每首歌的消音效果投 👍/👎 - YouTube 縮圖上會顯示大家覺得好用的比例，點進去
  之前就知道
• 派對模式 - 朋友掃 QR code，用手機把歌加進共用清單，然後輪流上場，歌詞同步跟著跑

免費，只需要一個帳號
Karafilt 完全免費，沒有廣告，也沒有付費版。用免費帳號登入一次即可；帳號隨時
可以在 karafilt.com 刪除。

關於歌詞
逐字時間軸來自 karalyr.com，一個開放的卡拉OK歌詞資料庫。還沒有時間軸的歌，在你
聽的時候會自動排進佇列 - 同一首歌越多人要，就越快做好。

隱私
去人聲 100% 在你的電腦上完成 - 音訊從來不會離開瀏覽器。只有歌名會送到歌詞資料庫
去比對。Karafilt 是開源的：https://github.com/lemara98

隱私權政策：https://karafilt.com/privacy

說明：擴充功能本身的介面是英文的，歌詞則是該首歌原本的語言。
```
